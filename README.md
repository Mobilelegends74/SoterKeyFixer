# Soter Key Fixer

KernelSU module that repairs SOTER Key issues on Android devices.

## Description
Automatically executes the repair script upon startup, fixing SOTER Key authentication issues caused by root solutions like KernelSU.

## Compatibility
- KernelSU / KernelSU Next
- Qualcomm devices

## Usage
Install via KernelSU module manager, then reboot.
To manually trigger the fix, use the Action button in KernelSU.
